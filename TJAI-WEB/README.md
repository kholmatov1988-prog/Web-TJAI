# TJAI-WEB

Отдельный веб-клиент TJAI. Исходники настольной программы и её `.exe` находятся вне этой папки и сайтом не изменяются.

## Быстрый запуск готовой версии

После установки зависимостей можно открыть `start_tjai_web.bat`. Он запустит локальный сервер разработки на компьютере и откроет сайт в браузере. Окно консоли нужно оставить открытым; для остановки нажмите Ctrl+C.

## Разработка и сборка

1. Установите Node.js 20.19+ или 22.12+.
2. Скопируйте `.env.example` в `.env.local`.
3. Заполните только публичные параметры Supabase:
   - `VITE_SUPABASE_URL` — адрес проекта Supabase;
   - `VITE_SUPABASE_ANON_KEY` — publishable key (или legacy anon key);
   - `VITE_ENABLE_GOOGLE_AUTH=false` оставить выключенным, пока Google provider не настроен в Supabase Dashboard.
4. В корне `TJAI-WEB` выполните `pnpm install`, затем `pnpm dev`.
5. Откройте локальный адрес, напечатанный Vite (обычно `http://127.0.0.1:5173`).

Для выпуска статических файлов выполните `pnpm build`; результат появится в `dist/` внутри этой папки. Перед быстрым запуском из `.bat` пересоберите сайт, если меняли исходники.


## Supabase Auth

Пользователи входят в тот же Supabase-проект, что и настольная TJAI. Для email confirmation добавьте локальный адрес сайта в Supabase Dashboard → Authentication → URL Configuration → Redirect URLs. Для локального запуска добавьте `http://127.0.0.1:5173` и `http://localhost:5173`. Перед публикацией добавьте точный адрес опубликованного сайта отдельно.

Регистрация доступна по электронной почте и паролю. Google sign-in необязателен: сначала настройте Google provider в Supabase, а затем включите `VITE_ENABLE_GOOGLE_AUTH=true`.

## Gemini и безопасность

Секретный Gemini API key не указывается в `.env.local` и не передаётся браузеру. Он остаётся в Supabase Dashboard → Edge Functions → Secrets как `GEMINI_API_KEY`; сайт вызывает серверную функцию `tjai-chat`. Не используйте Supabase service-role key в клиентской конфигурации. Publishable/anon key предназначен для клиента и ограничивается включёнными RLS-политиками.

Гостевой режим сохраняет поисковую историю в браузере. Чат с TJAI требует входа в аккаунт. Облачные записи аккаунтов защищаются существующими RLS-политиками. Действия админ-панели проверяются Edge Function `admin-users` на сервере.

Публикация, домен, тарифы и Android APK в этой версии не настраиваются.
